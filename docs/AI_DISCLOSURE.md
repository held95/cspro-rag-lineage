# AI assistance disclosure

This project was built with **Claude Code** (an AI coding assistant) working in the author's repository, on top of an
implementation plan (`docs/CSPRO_IMPLEMENTATION_PLAN.md`, `docs/CSPRO_24H_EXECUTION_PLAN.md`) and research notes
(`docs/research/`).

## What the assistant did
- Wrote or modified code and tests across `app/`, `tests/` and `finetune/`, ran the test suite, and committed the work
  (commits carry a `Co-Authored-By: Claude` trailer).
- In the most recent session specifically: fixed three over-strict API test assertions, wrote the security suite
  (`tests/security/`), repaired the training environment, adapted `finetune/train.py` to `transformers` 5 / TRL 1.x, ran the
  20-step smoke, the 75-step training run and the four evaluation arms, and generated the report with
  `python -m finetune.report`.
- Wrote this documentation.

## What the assistant did not do / cannot vouch for
- No claim here has been reviewed line by line by a second person; the author is expected to be able to explain every part.
- Reported numbers come from scripts (`finetune/results/*.json` -> `baseline_vs_adapted.md`), not from hand-typed values.
- Anything listed in `docs/LIMITATIONS.md` as not executed was not executed.
- The training data are synthetic, generated by `finetune/gen_dataset.py`; no real customer data were used.

## Reused code and third-party material
- **No code was knowingly copied from other projects or tutorials.** The application, test and fine-tune code in this repository
  was written for this assessment by the author with Claude Code; a generated snippet may still resemble public code.
- **Libraries** are installed from PyPI at the pinned versions in `requirements*.txt` (FastAPI, Pydantic, qdrant-client,
  httpx, pytest; torch, transformers, peft, trl, bitsandbytes for the fine-tune). **Models** are downloaded, not committed:
  `Qwen/Qwen3-1.7B`, `qwen3:4b-instruct-2507-q4_K_M` and `nomic-embed-text` (licences: see README, not re-verified).
- **Review guidance:** the text of several skills from a third-party security skill pack (a fork of `Claude-BugHunter`) was used
  as a checklist for one white-box security review; no code from it was copied, and it found the Unicode-smuggling gap fixed
  in `app/modules/generation/sanitize.py`.
